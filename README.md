Seat Planning App — Requirements
1. Events
   - Create/delete events.
   - Each event has its own guest list, tables, and seating arrangement.
   - Tables are independent between events.
2. Guest Management
   - Add single guest.
   - Bulk add guests.
   - Delete individual guest.
   - Search/find guest.
3. Table Management
   - Add/remove tables.
   - Each table has 8–10 seats.
   - Tables displayed in a tabular view.
4. Seat Assignment
   - Guests are drag-and-drop.
   - Drag unseated guest → seat.
   - Move guest between seats/tables.
   - Move guest back to unseated.
   - Swap guests when dropping onto an occupied seat.
5. Guest Status
   - Show Seated / Unseated.
   - For seated guests, show Table + Seat Number.
   - Show counts for total, seated, and unseated guests.
6. Colour Coding
   - Colour-code guests/cells.
   - Colour remains associated with the guest when moved.
7. Access & Sharing
   - Cloud-hosted.
   - Shareable URL.
   - Simple authentication to prevent unauthorized access.
   - Only one editor at a time; no real-time collaborative editing required.
8. Persistence
   - Changes automatically saved.
   - Seating plan persists across refreshes/sessions.
9. Hosting
   - MVP should run entirely on free-tier services.
